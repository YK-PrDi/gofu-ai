【第一优先·产品主体 = 所给白底图·防虚假宣传】
画面主体产品就是所给白底图里的那一个产品本身。外形、结构、层数/格数、部件形状与数量、颜色「{{colorName}}」、材质、比例，一律 1:1 复刻白底图：不得改结构、不得改色、不得美化、不得替换成别的款式、不得臆造白底图上没有的细节。
这条铁律有三个最易失守的落点，逐条执行：
① **左右对称**：成对部件（两侧树枝形挂钩、两边支腿、左右围栏）必须高度相同、角度镜像、长度一致、分叉形状相同，不得一高一低一长一短。波浪形卡槽各波峰波谷等高等宽、上下两道严格平行。顶部装饰件（三角头饰、圆珠）与主体连接处居中垂直不歪斜，圆珠是正球体、不得画成椭圆或与连杆熔成一团。架体不向任一侧倾斜，中轴线垂直于台面。
② **重复部件逐个点数**：成排部件（挂钩、卡位、吸盘、挂杆分格）对着白底图点数，分毫不差——最常见错误是把 N 个画成 N+1 个。宁可留白不凑数。画面文案写了具体个数时，实际数量必须与该数字一致。
③ **功能小图也是本款**：竖排功能小图、细节放大图里的产品同样必须是白底图这一款（同款同结构同色），只换景别/角度重画来演示功能，严禁拿别款或别的颜色充数。
金属线条要有**工业级硬边质感**：同一根杆从头到尾粗细一致、该直的笔直、该平行的严格平行，不得呈现塑料软管般的松垮弯曲。接水盘尺寸要与架体匹配、不得过大过小。
