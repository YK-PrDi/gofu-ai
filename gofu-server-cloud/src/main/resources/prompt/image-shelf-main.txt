【三维层级·按此顺序分层作画·最易出错处】
穿模的根源是没有想清楚"谁在谁前面"。作画时把画面**当成有确定前后层次的真实三维空间**，按下面的层序从后往前依次落笔，每一层都完整画完再画下一层：
1. 最后层：场景背景（墙面/台面）。
2. 中间层：**被收纳物**（锅盖、砧板、盘子等）——它们放在架体的卡位/层板/接水盘上，位置在架体前方杆件的**后面**。多件收纳物之间也有前后：靠后的那件被靠前的那件部分遮住，不得边缘融合成一体。
3. 最前层：**架体朝向镜头的那些杆件/框条/围栏**——这些杆件必须【完整、连续、不间断】地画在被收纳物的**前面**，把收纳物的相应部分**遮住**。
【判定标准·逐条自检】
· 凡是架体杆件与收纳物在画面上重叠的地方，**必须二者之一被另一个完全遮挡**，绝不允许出现"杆件从收纳物中间穿过去""收纳物的边缘嵌进杆件里""两者边缘融成一条线""杆件在收纳物表面若隐若现"这四种情形。
· 每个杆件从头到尾**粗细一致、走向连续**，不得在与收纳物交叠处变细、断开、消失或改变方向。
· 每件收纳物与承载面（卡槽/层板/盘底）之间要看得见**接触**：有落实的接触点、贴合的边界、以及朝光源反方向的落地阴影。看不出它靠什么支撑住 = 画错了。
· 玻璃锅盖等透明件：透过它能看到后面的东西（这是透明），但它的**金属边圈与提手是不透明实体**，与杆件重叠处必须有明确的前后遮挡，不能互相透视穿插。
